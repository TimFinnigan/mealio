# Mealio

A minimalist meal tracker. Log what you eat, when, and optionally how many calories. Everything is stored in your browser's localStorage, so there is no account, no server, and no data leaving your device.

## Features

- Quick entry: meal name, type (breakfast, lunch, dinner, snack), optional calories
- Meal type preselected based on the time of day
- History grouped by day with a daily calorie total
- Mobile-first layout with automatic light and dark mode
- Plain HTML, CSS, and JavaScript. No build step, no dependencies.

## Running locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```
