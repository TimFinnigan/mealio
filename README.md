# Mealio

A minimalist recipe saver. Save recipes with ingredients and instructions, browse them as clean cards, and search by title or ingredient. Everything is stored in your browser's localStorage, so there is no account, no server, and no data leaving your device.

## Features

- Save recipes with a title, ingredients (one per line), and step-by-step instructions
- Clean card list on a white background, tap a card to open the recipe
- Search by title or ingredient
- Edit and delete recipes
- Mobile-first layout
- Plain HTML, CSS, and JavaScript. No build step, no dependencies.

## Running locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```
